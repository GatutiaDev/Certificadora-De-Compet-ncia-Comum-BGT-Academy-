# 🎓 BGT Academy - Certificadora de Competência Comum

> Projeto Integrador voltado ao desenvolvimento de uma plataforma/ambiente de certificação e capacitação da **BGT Academy**, promovendo a gestão, validação e visualização de competências educacionais e técnicas.

---

## 📌 Sobre o Projeto

O **BGT Academy** é um projeto acadêmico/institucional (Projeto Integrador) focado na avaliação e certificação de competências essenciais. A plataforma tem como objetivo conectar o aprendizado teórico às habilidades práticas exigidas pelo mercado, disponibilizando:

- Interface interativa para visualização de trilhas de aprendizado e materiais de estudo.
- Design responsivo e acessível para fácil navegação entre módulos e conteúdos de avaliação.

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias base da web:

- **HTML5**: Estruturação semântica de páginas e seções da aplicação.
- **CSS3**: Estilização, layout responsivo e identidade visual.
